## Installation
You must source your own files. Copy the contents of the **VM zip** into `metroidprimeorigins/assets`:

```
assets/data.win
assets/BGM/
assets/controllerblacklist.csv
assets/controllertypes.csv
assets/gamecontrollerdb.txt
assets/sdl2.txt
assets/options.ini
```

## Troubleshooting
If you have no audio, you may need the newer gmloadernext.squashfs runtime. Pharos would update this for you, but if you installed manually then you need to update it yourself.
