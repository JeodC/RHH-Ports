## Installation
Download the game from https://caffinate.itch.io/mimis-delivery-dash and extract `data.win` and both .ogg files to `ports/mimisdeliverydash/assets`.

## Default Gameplay Controls
| Button | Action |
|--|--|
|D-PAD / JOYSTICK|Move around|
|A|Boost|
|B|Collect items|
|START|Pause|

## Runtimes

This port requires the following:

- [gmloadernext.squashfs](https://github.com/JeodC/RHH-Ports/raw/main/runtimes/gmloadernext.squashfs) placed in the `PortMaster/libs/` folder.

[Pharos](https://github.com/JeodC/RHH-Ports/releases/download/ports-latest/pharos.zip) will fetch it automatically when installing the port. Otherwise download it manually and add it to the correct folder.
